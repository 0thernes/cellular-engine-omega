# Threat Model (`B36` — STRIDE Analysis)

**Scope:** Native C11 CLI/library (`bin/omega_cell`, `bin/libomega_cell`), loopback Web Observatory (`web/server.mjs`), build/verification scripts (`scripts/`), and Lean 4 formal pipeline (`lean/`).  
**Deployment Assumption:** Offline local research workstation and informational GitHub Actions CI. `web/server.mjs` is **strictly loopback-only (`127.0.0.1`)** and unsupported for public internet exposure.

| STRIDE Category | Asset / Entry Point | Threat Scenario | Existing Control / Mitigation | Residual Risk |
| :--- | :--- | :--- | :--- | :--- |
| **Spoofing** | `web/server.mjs` HTTP requests | Malicious website on user's browser issues cross-origin or DNS-rebinding requests to `http://127.0.0.1:8791` | Strict loopback `Host` whitelist (`127.0.0.1` / `localhost` only), `Origin` and `Sec-Fetch-Site` validation returning `403`, strict `frame-ancestors 'none'` CSP | Low (local attacker with shell access already owns the host) |
| **Tampering** | C11 CLI telemetry -> Lean 4 receipt (`LiveC11Receipt.lean`) | Out-of-band editing of `LiveC11Receipt.lean` or `README.md` axiom blocks to mask a broken simulation or `sorry` | `build.ps1` / `build_linux.sh` regenerate `LiveC11Receipt.lean` live from `omega_cell --export-lean-trace`, `O63`/`O72` re-check equalities among the C-reported integer fields and digest strings (they compare the digests as strings and do not compute or verify any hash), `scripts/check_readme_axioms.py` and `CHECKSUMS.sha256` detect drift, CI emits SLSA build provenance (`actions/attest-build-provenance`) | Very Low (detectable because the build regenerates the receipt and re-checks its equalities; the detection is not cryptographic) |
| **Repudiation** | Experimental results & multi-seed sweeps | Cherry-picking favorable seeds or modifying stats post-hoc | `PREREGISTRATION.md` locks seeds `2026001`–`2026020` and Holm–Bonferroni thresholds before sweeps; raw per-seed CSV archived in `results/multiseed_stats.csv` + `data/MANIFEST.sha256` + `docs/run-log.md` | Very Low |
| **Information Disclosure** | `web/server.mjs` static file handler & git history | Path traversal (`GET /../server.mjs`, `GET /server.mjs`) or accidental secret commit | Explicit allowlist `ALLOWED_STATIC = {'index.html', 'app.js', 'styles.css'}` (`GET /server.mjs -> 404`), `X-Content-Type-Options: nosniff`, `.gitleaks.toml` + CI secret scanning, zero `.env` credentials used | Very Low |
| **Denial of Service** | `web/server.mjs` `/api/run` subprocess spawning & C11 CLI inputs | Flood of concurrent requests exhausting CPU/RAM, or crafted CLI seeds/flags triggering OOM/UB | `MAX_INFLIGHT = 2` concurrency cap returning HTTP `429`, per-request timeout, strict integer bounds (`parse_u64_strict`, `parse_mutant_strict`, exit `2` on invalid input), `-Wall -Wextra -Wshadow -Werror`, ASan/UBSan + `fuzz_omega_cli_codec.c` (`256` mutated inputs) | Low (loopback-only) |
| **Elevation of Privilege** | `web/server.mjs` spawning `omega_cell` | Shell command injection via query parameters (`?seed=...;id`) | Strict regex/integer parsing + `child_process.execFile` with explicit argv array (never `exec` or shell interpolation); zero `eval`/`new Function` | Very Low |
