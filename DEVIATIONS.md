# Deviations from Preregistration & Standard Templates

This document transparently records every intentional deviation from `PREREGISTRATION.md`, Build Standard v1.2.0 defaults, or external literature formulations, together with rationale and impact assessment.

| ID | Target | Deviation | Rationale | Impact on Validity |

| `DEV-03` | Local Windows `lean4lean` vs Linux CI | Local Windows `build.ps1` verifies all `100` theorems across `5` independent kernels (`lean`, `leanchecker`, `leanchecker-paranoid`, `con-leche --verified`, `con-ron --verified`, `nanoda_bin`) + live negative kernel test; Ubuntu Linux CI (`scripts/verify_lean_six_kernels.sh`) additionally runs `lake check --paranoid` (`lean4lean`) and `lake comparator --config comparator.json --paranoid` inside Linux `bwrap` namespaces | Reports exact per-platform kernel coverage without hiding Windows `bwrap` limitations | Full 6-kernel independence verified automatically on every push to `main` |
